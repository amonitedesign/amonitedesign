## About Amonite

**Amonite Design** crafts focused, aesthetic digital instruments for interior decorators, ceramicists, and boutique 3D printing artisans.

Traditional CAD software was built for mechanical assemblies, gearboxes, and aerospace tolerances—burdening designers with infinite feature trees, constraint solvers, and engineering overhead. Amonite eliminates that friction. We design quiet, tactile workspaces where designers sculpt through proportion, curve tension, fluting rhythms, and clay shrinkage compensation.

## Craft Philosophy

- **Tactile Over Technical:** Sliders map to physical pottery attributes—foot diameter, rim flair, rib count, wall thickness, and rotational twist—rather than abstract spline coordinates.
- **Immediate Feedback:** Every contour recalculates live at 60 FPS in WebGL with soft shadow contact planes and physical clay materials (Sandstone Bisque, Raw Terracotta, Gloss Porcelain, Matte Obsidian).
- **Zero Cloud Intermediaries:** Your forms never leave your hardware. No accounts, no paywalls on core creative work, and zero tracking cookies.

## Physical Fabrication Standards

Every form generated in Amonite is validated against rigorous physical fabrication rules:

| Specification | Standard | Practical Outcome |
| :--- | :--- | :--- |
| **Mesh Manifoldness** | 100% 2-Manifold | Guaranteed watertight solid; zero slicer repair warnings in Bambu Studio / PrusaSlicer / Cura |
| **Spiralize / Vase Mode** | Single Continuous Contour | Continuous perimeter extrusion with zero seam marks, zero stringing, and rapid print times |
| **Shrinkage Compensation** | Real-time Scale Multiplier | Pre-scales geometry (`+9.5%` Terracotta, `+11.8%` Stoneware, `+14.2%` Porcelain) to match final fired size |
| **Production Vectoring** | STL · DXF · SVG | Client-side export for FDM, clay paste printers, slip-cast plaster mold generation, and CNC wire routing |
